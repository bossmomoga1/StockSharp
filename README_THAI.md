# StockSharp Trading Platform - คู่มือการใช้งาน

## สถานะปัจจุบัน

✅ .NET SDK 8.0 ติดตั้งสำเร็จแล้ว
❌ โปรเจกต์หลักยังไม่สามารถ build ได้เนื่องจากปัญหากับ Localization project
❌ Sample projects ส่วนใหญ่ใช้ net6.0-windows ซึ่งไม่สามารถรันบน Linux ได้

## ทางเลือกสำหรับการใช้งาน

### 1. ใช้ Docker (แนะนำ)
docker run -it --rm mcr.microsoft.com/dotnet/sdk:8.0 bash
### 2. ใช้ Windows หรือ WSL2
StockSharp ออกแบบมาสำหรับ Windows เป็นหลัก
